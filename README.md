# miniCDN

CDNの仕組みを理解するために、自作のミニCDNを段階的に実装することを目指す学習用プロジェクト。

## 目的
- CDNの基本構造（Origin / Cache / Proxy）を理解する
- HTTPキャッシュの挙動を実装して確認する
- 簡単なセキュリティ機構（IP制限・レート制限など）を試す
- 可視化ダッシュボードを作り、挙動を観察できるようにする

## 方針
- ゼロから段階的に実装する
- 一気に完成させず、理解しながら進める
- 各ステップを記録する
- 実験用の小規模CDNとして設計する

## 想定構成
Client -> CDN Server -> Origin Server

## 今後の予定（暫定）
- STEP0: CDNとHTTPの整理（設計）
- STEP1: Originサーバの実装
- STEP2: Proxy（CDNサーバ）の実装
- STEP3: キャッシュ機構の追加
- STEP4: ダッシュボードの追加
- STEP5: セキュリティ機構の追加
